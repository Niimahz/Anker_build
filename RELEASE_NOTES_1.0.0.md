# Anker 1.0.0

Anker is a free and open-source iOS utility for browsing, managing downloads, extracting supported archives, and preparing locally supplied PC game files for transfer to other apps.

## Features
- WebKit browser and download management with configurable concurrent downloads.
- Local ZIP, RAR/RAR5, 7z and supported archive extraction (format and storage limitations apply).
- Files dashboard, prepared Games library, local user-provided cover images and export.
- Windows executable and BAT/CMD inspection (scripts are never executed).
- Optional Buy Me a Coffee link in Files; no features require payment.

## Download and install
The attached `Anker-v1.0.0-unsigned.ipa` is **unsigned** and is not an App Store application. It requires an appropriate iOS installation/signing or compatible container workflow. The `SHA256SUMS.txt` attachment lets users verify file integrity.

## Important
Anker does **not** run Windows games, supply game downloads, bypass licensing, or guarantee compatibility with Madeira. Only import files you are entitled to use.
